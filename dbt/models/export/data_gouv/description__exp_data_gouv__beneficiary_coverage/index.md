# Table: Beneficiary coverage numerator (data.gouv.fr)

The `exp_data_gouv__beneficiary_coverage` table is the open data version of [exp_vidoc_beneficiary_coverage](https://pass-culture.github.io/data-gcp/dbt/models/export/data_gouv/vidoc/description__exp_vidoc_beneficiary__coverage.md): number of beneficiaries who reached a milestone age over the last 12 months, by department of residence.

## Table description

Published on data.gouv.fr as the `beneficiary_coverage` resource. It is the numerator of the [coverage rate](https://pass-culture.github.io/data-gcp/dbt/vidoc_kpis/beneficiaries/beneficiary_coverage_rate/index.md). The denominator (INSEE population estimates) is **not** republished: it is INSEE data, and its computation is public in [metrics_population\_\_coverage](https://github.com/pass-culture/data-gcp/tree/master/orchestration/dags/data_gcp_dbt/models/metrics/population).

Same perturbed counts as the vidoc export, closed months only, geographic codes formatted as in [exp_data_gouv_beneficiary](https://pass-culture.github.io/data-gcp/dbt/models/export/data_gouv/description__exp_data_gouv__beneficiary/index.md).

**Grain**: `partition_month`, `department_name`, `milestone_age`.

| name                               | data_type | description                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                    | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                                                                                                                                        |
| region_code                        | STRING    | The official code of the region (région) containing the IRIS area.                                                                                                                                                                                                                                                                                                                             |
| region_name                        | STRING    | The official name of the region containing the IRIS area.                                                                                                                                                                                                                                                                                                                                      |
| department_code                    | STRING    | The official code of the department (département) containing the IRIS area.                                                                                                                                                                                                                                                                                                                    |
| department_name                    | STRING    | The official name of the department containing the IRIS area.                                                                                                                                                                                                                                                                                                                                  |
| milestone_age                      | INT64     | Age milestone in whole years, used to determine users eligibility: months between birth month and the observation month divided by 12, kept when it is an integer, so milestone_age N is the cohort turning N that month. Stored as INT64 in beneficiary coverage models and in exp_vidoc\_\_population_coverage, STRING in int_kpi\_\_population_coverage and metrics_population\_\_coverage. |
| total_beneficiaries_last_12_months | INT64     | Rolling sum of distinct users over the last 12 months for a given age and department: the sum of monthly distinct-user counts over the current and 11 previous months, so a user active in several months is counted once per month.                                                                                                                                                           |
