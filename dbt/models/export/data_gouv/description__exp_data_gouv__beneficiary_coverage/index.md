# Table: Beneficiary coverage numerator (data.gouv.fr)

The `exp_data_gouv__beneficiary_coverage` table is the number of beneficiaries who reached a milestone age over the last 12 months, by department of residence. Milestone ages 16 to 19 give the coverage rates 15+ to 18+.

## Table description

Published on data.gouv.fr as the `beneficiary_coverage` resource. It is the numerator of the [coverage rate](https://pass-culture.github.io/data-gcp/dbt/kpis/beneficiaries/beneficiary_coverage_rate/index.md). The denominator (INSEE population estimates) is **not** republished: it is INSEE data, and its computation is public in [metrics_population\_\_coverage](https://github.com/pass-culture/data-gcp/tree/master/orchestration/dags/data_gcp_dbt/models/metrics/population).

Counts come from the perturbed base [exp_base\_\_beneficiary_coverage](https://pass-culture.github.io/data-gcp/dbt/models/export/export_base/description__exp_base__beneficiary_coverage/index.md), closed months only, geographic codes formatted as in [exp_data_gouv_beneficiary](https://pass-culture.github.io/data-gcp/dbt/models/export/data_gouv/description__exp_data_gouv__beneficiary/index.md).

**Grain**: `partition_month`, `department_name`, `milestone_age`.

| name                               | data_type | description                                                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                    | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                                                                                                                    |
| region_code                        | STRING    | The official code of the region (région) containing the IRIS area.                                                                                                                                                                                                                                                                                                         |
| region_name                        | STRING    | The official name of the region containing the IRIS area.                                                                                                                                                                                                                                                                                                                  |
| department_code                    | STRING    | The official code of the department (département) containing the IRIS area.                                                                                                                                                                                                                                                                                                |
| department_name                    | STRING    | The official name of the department containing the IRIS area.                                                                                                                                                                                                                                                                                                              |
| milestone_age                      | INT64     | Age milestone in whole years, used to determine users eligibility: months between birth month and the observation month divided by 12, kept when it is an integer, so milestone_age N is the cohort turning N that month. Stored as INT64 in the beneficiary and population coverage exports, STRING in int_kpi\_\_population_coverage and metrics_population\_\_coverage. |
| total_beneficiaries_last_12_months | INT64     | Rolling sum of distinct users over the last 12 months for a given age and department: the sum of monthly distinct-user counts over the current and 11 previous months, so a user active in several months is counted once per month.                                                                                                                                       |
