# Table: Beneficiaries (perturbed base)

The `exp_base__beneficiary` table holds the beneficiary counts at their finest grain, already protected with the cell key perturbation method. It is the single place where the statistical confidentiality rules of these counts are applied.

## Table description

Every export reads this table and only **sums** its perturbed cells, never re-perturbs them, so that the figures published by every tool match for a given territory and month:

- [exp_vidoc_beneficiary](https://pass-culture.github.io/data-gcp/dbt/models/export/vidoc/description__exp_vidoc_beneficiary/index.md): `select *` for the ministry's vidoc tool;
- [exp_data_gouv_beneficiary](https://pass-culture.github.io/data-gcp/dbt/models/export/data_gouv/description__exp_data_gouv__beneficiary/index.md): lot 1 columns, closed months, for data.gouv.fr;
- external reporting: national, regional and departmental figures are sums of these cells.

Columns, grain and capping rules are described in [exp_vidoc_beneficiary](https://pass-culture.github.io/data-gcp/dbt/models/export/vidoc/description__exp_vidoc_beneficiary/index.md). See [Statistical confidentiality](https://pass-culture.github.io/data-gcp/dbt/references/statistical_confidentiality/index.md).
