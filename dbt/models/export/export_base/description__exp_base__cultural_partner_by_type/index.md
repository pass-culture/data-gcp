# Table: Cultural partners by venue type (export base)

The `exp_base__cultural_partner_by_type` table holds the monthly active and cumulative activated cultural partners by venue type and venue geography, at the finest grain (municipality). Counts are out of scope of the statistical secret, which protects economic values of a business, not counts of establishments (see [exp_base\_\_cultural_partner](https://pass-culture.github.io/data-gcp/dbt/models/export/export_base/description__exp_base__cultural_partner_by_type/description__exp_base__cultural_partner.md)).

## Table description

A partner can match several types, and `tag_*` rows are labels (subsets of a type): never sum over `partner_type`. Use [exp_base\_\_cultural_partner](https://pass-culture.github.io/data-gcp/dbt/models/export/export_base/description__exp_base__cultural_partner/index.md) for totals. Cells are additive over geography for a given type.

Read by [exp_vidoc_cultural_partner_by_type](https://pass-culture.github.io/data-gcp/dbt/models/export/vidoc/description__exp_vidoc_cultural_partner__by_type/index.md) and `external_reporting__cultural_partner` (active individual partners by type).
