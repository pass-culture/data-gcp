# Table: Diversity by offer category (perturbed base)

The `exp_base__diversity_by_category` table holds the diversity_by_category counts at their finest grain, already protected with the cell key perturbation method. It is the single place where the statistical confidentiality rules of these counts are applied.

## Table description

Every export reads this table and only **sums** its perturbed cells, never re-perturbs them, so that the figures published by every tool match for a given territory and month:

- [exp_vidoc_diversity_by_category](https://pass-culture.github.io/data-gcp/dbt/models/export/vidoc/description__exp_vidoc_diversity__by_category/index.md): `select *` for the ministry's vidoc tool;
- [exp_data_gouv_diversity_by_category](https://pass-culture.github.io/data-gcp/dbt/models/export/data_gouv/description__exp_data_gouv__diversity_by_category/index.md): lot 1 columns, closed months, for data.gouv.fr;
- external reporting: national, regional and departmental figures are sums of these cells.

Columns, grain and capping rules are described in [exp_vidoc_diversity_by_category](https://pass-culture.github.io/data-gcp/dbt/models/export/vidoc/description__exp_vidoc_diversity__by_category/index.md). See [Statistical confidentiality](https://pass-culture.github.io/data-gcp/dbt/references/statistical_confidentiality/index.md).
