The `exp_vidoc__top_offer` model provides the monthly ranking of the top 50 booked offers (items) at national, regional, and departmental levels. It is designed to be exported to the Ministry for Vidoc visualization.

## Table Description

Each row represents an item included in the top 50 most booked items for a given month and geographic area.

**Grain**: `partition_month`, `geo_level`, `geo_value`, `offer_rank`.

Item attributes (`offer_name`, `offer_category_id`, `offer_subcategory_id`) are consolidated to the canonical monthly version to avoid multi-vendor duplication.

| name                   | data_type | description                                                                                                                                                                                                                                                                         |
| ---------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month        | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                             |
| geo_level              | STRING    | Geographic scale used to compute the ranking ('national', 'region', or 'department').                                                                                                                                                                                               |
| geo_value              | STRING    | Name or identifier of the geographic area corresponding to the aggregation level ('NAT', region name, or department name).                                                                                                                                                          |
| item_id                | STRING    | Identifier of the work (item) the offer belongs to, used internally by the data science team; several offers of the same book or film share an item_id.                                                                                                                             |
| offer_category_id      | STRING    | Identifier of the offer category, which groups offer subcategories (offer_subcategory_id): the cultural partner picks the subcategory from a predefined list when creating the offer, and the category follows from it. Rows of retired subcategories can carry a retired category. |
| offer_subcategory_id   | STRING    | Identifier for the subcategory of the offer. Determined by the cultural partner via a list of pre-set options. Each subcategory belongs to exactly one offer category (offer_category_id).                                                                                          |
| offer_name             | STRING    | Name of the offer as it appears in the application.                                                                                                                                                                                                                                 |
| total_booking_amount   | FLOAT64   | Total amount generated by the bookings.                                                                                                                                                                                                                                             |
| total_booking_quantity | INT64     | Total quantity of items booked.                                                                                                                                                                                                                                                     |
| offer_rank             | INT64     | Rank position of the offer based on total booking revenue generated over the period, in descending order (from 1 to 50).                                                                                                                                                            |
