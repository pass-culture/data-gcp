The `exp_vidoc__top_venue` model provides the monthly ranking of the top 50 partner cultural venues based on booking revenue at national, regional, and departmental levels. It is designed to be exported to the Ministry for Vidoc visualization.

## Table Description

Each row represents a venue included in the top 50 venues by used booking amount for a given month and geographic area.

**Grain**: `partition_month`, `geo_level`, `geo_value`, `venue_rank`.

| name                 | data_type | description                                                                                                                |
| -------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------- |
| partition_month      | DATE      | Indicates the first day of the month the KPI refers to.                                                                    |
| geo_level            | STRING    | Geographic scale used to compute the ranking ('national', 'region', or 'department').                                      |
| geo_value            | STRING    | Name or identifier of the geographic area corresponding to the aggregation level ('NAT', region name, or department name). |
| venue_id             | STRING    | Unique identifier for the venue.                                                                                           |
| venue_name           | STRING    | Name of the venue.                                                                                                         |
| offerer_name         | STRING    | Name of the offerer.                                                                                                       |
| total_booking_amount | FLOAT64   | Total amount generated by the bookings.                                                                                    |
| venue_rank           | INT64     | Rank position of the venue based on total booking revenue generated over the period, in descending order (from 1 to 50).   |
