The `external_reporting__individual` model provides aggregated key indicators related to pass Culture government priority politic for the individual part. It is designed for automated export, especially in Excel format.

## Table Description

Each row represents a key indicator calculated for a specific month and geographic aggregation level. A lexique details the meaning of each kpi_name here: https://docs.google.com/spreadsheets/d/13Epof9MJbtN7srmDIld3-7QN0Hq6WpX7/edit?usp=sharing&ouid=113033507472186952579&rtpof=true&sd=true

| name                 | data_type | description                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month      |           | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                                                                                                                                                                                                          |
| updated_at           |           | The actual date when the data refresh was executed.                                                                                                                                                                                                                                                                                                                                                                                                              |
| dimension_name       |           | The geographic agregation of the kpi. Can be National, Regional or Departemental.                                                                                                                                                                                                                                                                                                                                                                                |
| dimension_value      |           | The name of the geographic agregation of the kpi, if it exists. (region name, department name)                                                                                                                                                                                                                                                                                                                                                                   |
| kpi_name             |           | The name of the kpi.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| numerator            |           | The numerator of the computed kpi.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| denominator          |           | The denominator of the computed kpi.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| kpi                  |           | The value of the kpi. Equals to numerator divided by denominator.                                                                                                                                                                                                                                                                                                                                                                                                |
| aggregation          |           | How to aggregate `numerator` and `denominator` over several months: `flow` = sum the months, `stock` = take the last month (the value is already scholar year to date, or a snapshot).                                                                                                                                                                                                                                                                           |
| label                |           | Display name of the territory: EPCI or municipality name for EPCI and COM, dimension_value otherwise.                                                                                                                                                                                                                                                                                                                                                            |
| intitule             |           | Display title of the territory, unique across levels so that it can be used alone as the territory filter: 'Name (code)' for EPCI and COM, 'Région Name' for REG, 'Académie de Name' (or "Académie d'Name") for ACAD, 'Rapport National' for NAT, dimension_value for DEP.                                                                                                                                                                                       |
| is_secret_stat       |           | True when the KPI is measured on the cultural partner (venue) geography and the territory (COM, EPCI or DEP) is subject to statistical secrecy at the last complete month, over the 6 or the 48-month rolling window (is\_**secret_stat of the statistical_secret\_\_cultural_partner** models). numerator, denominator and kpi are then NULL on every month. KPIs measured on the beneficiary or school geography are never secret, nor are REG, ACAD and NAT.  |
| is_low_count         |           | True when the KPI is accounted for by 1 to 4 beneficiaries of the territory over the whole history (see external_reporting\_\_beneficiary_booking_bookers): numerator, denominator and kpi are then NULL on every month. Also true on the months where an average or a share by person (montant_moyen\_*, pct_beneficiaires_ayant_reserve\_*) is computed over 1 to 4 beneficiaries. Beneficiary counts are blurred instead (cell key method) and never flagged. |
| is_national_only     |           | True on the rows added for a KPI published at NAT but not at this territory level (e.g. coverage rates): numerator, denominator and kpi are NULL, only the national\_\* columns are filled, so that reports filtered on a territory still show the national value.                                                                                                                                                                                               |
| secret_reason        |           | Message to display instead of the KPI when it is masked, whatever the rule (statistical secret on cultural partners, or fewer than 5 beneficiaries behind the KPI): 'Données non disponibles (secret statistique)'. NULL otherwise. is_secret_stat and is_low_count tell the rule apart.                                                                                                                                                                         |
| secret_detail        |           | Internal detail of the rule behind a masked KPI, not to be published: the statistical secret reason of the territory with its side and rolling window (e.g. 'Nombre de partenaires faible (< 3) (individuel, 6 mois)'), or the fewer than 5 beneficiaries rule. NULL when the KPI is not masked.                                                                                                                                                                 |
| national_numerator   |           | Numerator of the same KPI and month at national level (NAT row), so that a report filtered on a territory can show the national figure from the same rows.                                                                                                                                                                                                                                                                                                       |
| national_denominator |           | Denominator of the same KPI and month at national level (NAT row).                                                                                                                                                                                                                                                                                                                                                                                               |
| national_kpi         |           | Value of the same KPI and month at national level (NAT row). NULL when the KPI is not published at NAT.                                                                                                                                                                                                                                                                                                                                                          |
