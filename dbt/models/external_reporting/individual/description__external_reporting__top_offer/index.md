title: Top offer Indicators description: Key indicators from the `external_reporting__top_offer` model.

______________________________________________________________________

The `external_reporting__top_offer` model provides a monthly aggregated list of top offers ranked by amount generated. It is designed for automated export, especially in Excel format.

## Table Description

A lexique details the meaning of each kpi_name here: https://docs.google.com/spreadsheets/d/13Epof9MJbtN7srmDIld3-7QN0Hq6WpX7/edit?usp=sharing&ouid=113033507472186952579&rtpof=true&sd=true

| name                        | data_type | description                                                                                                                                                                                                                                                                         |
| --------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month             |           | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                             |
| updated_at                  |           | The actual date when the data refresh was executed.                                                                                                                                                                                                                                 |
| dimension_name              |           | The geographic agregation of the kpi. Can be National, Regional or Departemental.                                                                                                                                                                                                   |
| dimension_value             |           | The name of the geographic agregation of the kpi, if it exists. (region name, department name)                                                                                                                                                                                      |
| item_id                     |           | Identifier of the work (item) the offer belongs to, used internally by the data science team; several offers of the same book or film share an item_id.                                                                                                                             |
| offer_category_id           |           | Identifier of the offer category, which groups offer subcategories (offer_subcategory_id): the cultural partner picks the subcategory from a predefined list when creating the offer, and the category follows from it. Rows of retired subcategories can carry a retired category. |
| offer_subcategory_id        |           | Identifier for the subcategory of the offer. Determined by the cultural partner via a list of pre-set options.                                                                                                                                                                      |
| offer_name                  |           | Name of the offer as it appears in the application.                                                                                                                                                                                                                                 |
| total_booking_amount        |           | Total amount generated by the bookings.                                                                                                                                                                                                                                             |
| total_booking_quantity      |           | Total quantity of items booked.                                                                                                                                                                                                                                                     |
| total_booking_amount_ranked |           | The rank of the total amount generated by the bookings. As opposed to the other category booked.                                                                                                                                                                                    |
