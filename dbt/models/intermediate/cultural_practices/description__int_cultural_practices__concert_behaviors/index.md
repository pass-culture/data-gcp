# Table: Cultural Practices 2018 — Concert behaviors

The `int_cultural_practices__concert_behaviors` table captures concert-going behaviors from the DEPS "Cultural Practices 2018" survey.

## Table description

| name                 | data_type | description                                                                              |
| -------------------- | --------- | ---------------------------------------------------------------------------------------- |
| respondent_id        |           | Survey respondent identifier.                                                            |
| alone                |           | 1 if the respondent usually attends concerts alone, else 0.                              |
| with_partner         |           | 1 if the respondent usually attends concerts with their partner, else 0.                 |
| with_children        |           | 1 if the respondent usually attends concerts with their children, else 0.                |
| with_grandchildren   |           | 1 if the respondent usually attends concerts with their grandchildren, else 0.           |
| with_relatives       |           | 1 if the respondent usually attends concerts with other relatives, else 0.               |
| with_friends         |           | 1 if the respondent usually attends concerts with friends, else 0.                       |
| with_organized_group |           | 1 if the respondent usually attends concerts within an organized group, else 0.          |
| no_general_rule      |           | 1 if the respondent has no general rule regarding who they attend concerts with, else 0. |
| would_miss_concert   |           | Whether the respondent would miss going to concerts if they no longer could.             |
