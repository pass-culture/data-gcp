# Table: Cultural Practices 2018 — Concert genres

The `int_cultural_practices__concert_genres` table captures concert attendance by music genre informations from the DEPS "Cultural Practices 2018" survey.

## Table description

| name              | data_type | description                                                                               |
| ----------------- | --------- | ----------------------------------------------------------------------------------------- |
| respondent_id     |           | Survey respondent identifier.                                                             |
| music_genre       |           | Music genre.                                                                              |
| attended_lifetime |           | 1 if the respondent attended a concert of this genre at least once in their life, else 0. |
| attended_last_12m |           | 1 if the respondent attended a concert of this genre in the last 12 months, else 0.       |
