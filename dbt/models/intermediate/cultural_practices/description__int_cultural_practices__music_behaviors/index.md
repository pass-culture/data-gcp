# Table: Cultural Practices 2018 — Music behaviors

The `int_cultural_practices__music_behaviors` table captures music listening behaviors from the DEPS "Cultural Practices 2018" survey.

## Table description

| name                          | data_type | description                                                                       |
| ----------------------------- | --------- | --------------------------------------------------------------------------------- |
| respondent_id                 |           | Survey respondent identifier.                                                     |
| listening_frequency_code      |           | Raw survey code for music listening frequency.                                    |
| support_cd_cassette           |           | 1 if the respondent listens to music on CD or cassette, else 0.                   |
| support_vinyl                 |           | 1 if the respondent listens to music on vinyl, else 0.                            |
| support_streaming_specialized |           | 1 if the respondent listens to music via a specialized streaming service, else 0. |
| support_streaming_other       |           | 1 if the respondent listens to music via another streaming service, else 0.       |
| support_digital_files         |           | 1 if the respondent listens to music via digital files, else 0.                   |
| support_radio                 |           | 1 if the respondent listens to music via the radio, else 0.                       |
| support_tv                    |           | 1 if the respondent listens to music via the television, else 0.                  |
| music_at_home_frequency_code  |           | Raw survey code for how often the respondent listens to music at home.            |
| active_listening_code         |           | Raw survey code for how often the respondent actively listens to music.           |
| music_importance_code         |           | Raw survey code for the importance of music to the respondent.                    |
| listening_frequency           |           | How often the respondent listens to music.                                        |
| foreign_language_music        |           | Whether the respondent listens to music in a foreign language.                    |
| music_at_home_frequency       |           | How often the respondent listens to music at home.                                |
| active_listening              |           | How often the respondent actively listens to music.                               |
| music_importance              |           | How important music is to the respondent.                                         |
