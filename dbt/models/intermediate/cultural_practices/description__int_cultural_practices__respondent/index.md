# Table: Cultural Practices 2018 — Respondent

The `int_cultural_practices__respondent` table captures respondent-level socio-demographics from the DEPS "Cultural Practices 2018" survey.

## Table description

| name           | data_type | description                               |
| -------------- | --------- | ----------------------------------------- |
| respondent_id  |           | Survey respondent identifier.             |
| gender         |           | Respondent gender.                        |
| age            |           | Respondent age.                           |
| age_group      |           | Age bracket label.                        |
| income         |           | Household income bracket label.           |
| household_type |           | Household type label.                     |
| household_size |           | Number of people living in the household. |
