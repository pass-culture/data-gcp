# Table: Institutional Event Flattened

The `int_firebase__institutional_event_flattened` table stores every Google Analytics 4 event tracked on the institutional website (pass.culture.fr), one row per event, with the event parameters flattened into columns.

## Table description

The table is built from the raw GA4 export of the institutional website (`raw.firebase_institutional_events`). It is imported daily from the `pc-site-instit-production` project, located in europe-west9, through a staging table copied to europe-west1.

Each row is an event: page views (`page_view`, `pageView`), sessions (`session_start`, `first_visit`, `user_engagement`), clicks and scrolls, and custom events such as `downloadApp`, `goToLoginNative`, `goToSignUpPro` or `consent.answer`.

The website is public: users are identified by browser only (`user_pseudo_id`) and `user_id` is always empty. A session is identified by the pair (`user_pseudo_id`, `ga_session_id`). There is no event-level unique key in the GA4 export. A few events come from the testing website: filter on `device_hostname = 'pass.culture.fr'` to keep production traffic only.

The table is incremental and partitioned on `event_date`: each run overwrites the last 3 days.

| name                            | data_type | description                                                                                                                                                                                         |
| ------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| event_date                      | DATE      | The date when the event occurred, used for partitioning the data.                                                                                                                                   |
| event_name                      | STRING    | The name of the event. For screen views, it concatenates the event name with the Firebase screen name.                                                                                              |
| user_pseudo_id                  | STRING    | Firebase pseudonymous identifier of the app instance (the device, or the browser for web tracking), used for tracking purposes. One person can have several, and people sharing a device share one. |
| user_id                         | STRING    | Unique identifier for a user.                                                                                                                                                                       |
| platform                        | STRING    | The platform on which the event was recorded, such as iOS or Android.                                                                                                                               |
| event_timestamp                 | TIMESTAMP | The exact timestamp when the event was recorded.                                                                                                                                                    |
| user_first_touch_timestamp      | TIMESTAMP | Timestamp of the first visit of the browser (user_pseudo_id) on the institutional website.                                                                                                          |
| device_category                 | STRING    | The category of the user's device, such as mobile, tablet, or desktop.                                                                                                                              |
| device_operating_system         | STRING    | The operating system of the user's device, such as Windows, macOS, iOS, or Android.                                                                                                                 |
| device_operating_system_version | STRING    | The version of the operating system on the user's device.                                                                                                                                           |
| device_browser                  | STRING    | The web browser used by the user, such as Chrome, Firefox, or Safari.                                                                                                                               |
| device_browser_version          | STRING    | The version of the web browser used by the user.                                                                                                                                                    |
| device_hostname                 | STRING    | Hostname of the institutional website on which the event was recorded (pass.culture.fr, or the testing website).                                                                                    |
| geo_country                     | STRING    | Country of the user.                                                                                                                                                                                |
| geo_region                      | STRING    | Region of the user, as geolocated by Google Analytics from the IP address.                                                                                                                          |
| geo_city                        | STRING    | City of the user, as geolocated by Google Analytics from the IP address.                                                                                                                            |
| user_traffic_campaign           | STRING    | Name of the marketing campaign that first acquired the user (first-touch attribution).                                                                                                              |
| user_traffic_medium             | STRING    | Medium of the marketing campaign that first acquired the user (first-touch attribution).                                                                                                            |
| user_traffic_source             | STRING    | Source of the marketing campaign that first acquired the user (first-touch attribution).                                                                                                            |
| ga_session_id                   | INT64     | Google Analytics session identifier (session start unix timestamp). Unique only when combined with user_pseudo_id.                                                                                  |
| ga_session_number               | INT64     | The number of the session during which the visit occurred, indicating the sequence of user sessions.                                                                                                |
| engagement_time_msec            | INT64     | Time in milliseconds the page was in the foreground since the previous engagement event.                                                                                                            |
| entrances                       | INT64     | Equals 1 when the page view is the first page of the session (landing page).                                                                                                                        |
| percent_scrolled                | INT64     | Percentage of the page scrolled, set on scroll events. Always 90: GA4 sends the scroll event once the user reaches 90% of the page.                                                                 |
| engaged_session_event           | INT64     | Equals 1 when the event belongs to an engaged session.                                                                                                                                              |
| page_location                   | STRING    | The location of the page where the event occurred, typically a URL or path.                                                                                                                         |
| page_title                      | STRING    | Title of the page on which the event occurred.                                                                                                                                                      |
| page_referrer                   | STRING    | The referrer page that led to the current page where the event occurred.                                                                                                                            |
| origin                          | STRING    | Path of the page on which the event occurred, sent by the institutional website tracking plan.                                                                                                      |
| source                          | STRING    | Source of the marketing campaign that generated the session (utm_source).                                                                                                                           |
| medium                          | STRING    | Medium of the marketing campaign that generated the session (utm_medium).                                                                                                                           |
| campaign                        | STRING    | Name of the marketing campaign that generated the session (utm_campaign).                                                                                                                           |
| term                            | STRING    | Paid search keyword of the marketing campaign that generated the session (utm_term).                                                                                                                |
| ignore_referrer                 | STRING    | Equals 'true' when the referrer is ignored for attribution (internal or excluded referral).                                                                                                         |
| link_url                        | STRING    | URL of the clicked link, set on outbound click and file_download events.                                                                                                                            |
| link_domain                     | STRING    | Domain of the clicked outbound link.                                                                                                                                                                |
| link_text                       | STRING    | Text of the clicked link, set on file_download events.                                                                                                                                              |
| link_classes                    | STRING    | CSS classes of the clicked link element.                                                                                                                                                            |
| outbound                        | STRING    | Equals 'true' when the clicked link leads to another domain.                                                                                                                                        |
| file_name                       | STRING    | Path of the downloaded file, set on file_download events.                                                                                                                                           |
| file_extension                  | STRING    | Extension of the downloaded file, set on file_download events.                                                                                                                                      |
| privacy_consent_type            | STRING    | Consent flag sent with the cookie banner answer ('true' or 'false'), set on consent.answer events.                                                                                                  |
| privacy_consent_value           | STRING    | Answer given by the user to the cookie banner ('full' or 'refusal'), set on consent.answer events.                                                                                                  |
| session_engaged                 | STRING    | '1' when the session is engaged (lasted more than 10 seconds, had 2+ page views or a key event), '0' otherwise.                                                                                     |
