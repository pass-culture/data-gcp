# Table: Cultural Practices 2018 — Festival

The `mrt_cultural_practices__music_festival` table captures festival-going information enriched with respondent socio-demographics

## Table description

| name                       | data_type | description                                                                   |
| -------------------------- | --------- | ----------------------------------------------------------------------------- |
| respondent_id              |           | Survey respondent identifier.                                                 |
| attended_festival_last_12m |           | Whether the respondent attended a festival in the last 12 months.             |
| festival_would_miss        |           | Whether the respondent would miss going to festivals if they no longer could. |
