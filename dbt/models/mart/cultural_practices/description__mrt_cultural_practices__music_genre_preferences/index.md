# Table: Cultural Practices 2018 — Music genre preferences (mart)

The `mrt_cultural_practices__music_genre_preferences` table captures music genre preferences enriched with respondent socio-demographics.

## Table description

| name             | data_type | description                                                  |
| ---------------- | --------- | ------------------------------------------------------------ |
| respondent_id    |           | Survey respondent identifier.                                |
| music_genre      |           | Music genre.                                                 |
| listens_to_genre |           | 1 if the respondent listens to this genre, else 0.           |
| likes_genre      |           | 1 if the respondent particularly likes this genre, else 0.   |
| dislikes_genre   |           | 1 if the respondent does not like this genre at all, else 0. |
| gender           |           | Respondent gender.                                           |
| age_group        |           | Age bracket label.                                           |
| income           |           | Household income bracket label.                              |
| household_type   |           | Household type label.                                        |
