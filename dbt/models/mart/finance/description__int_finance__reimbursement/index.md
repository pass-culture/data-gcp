The `int_finance__reimbursement` table computes finance amounts by booking_used_date like the reimbursement amount and the contribution amount. It is aggregated by category, departement and region.

## Table description

| name                      | data_type | description                                                                                                                                                                                                                                                                         |
| ------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| booking_used_date         |           | Date when the booking was used.                                                                                                                                                                                                                                                     |
| venue_department_code     |           | Department code of the venue.                                                                                                                                                                                                                                                       |
| venue_department_name     |           | Department name where of the venue.                                                                                                                                                                                                                                                 |
| venue_region_name         |           | Region name where the venue is located.                                                                                                                                                                                                                                             |
| venue_epci_code           |           | EPCI code of the venue.                                                                                                                                                                                                                                                             |
| venue_city_code           |           | INSEE code of the city where the venue is located, at the arrondissement level for Paris, Lyon and Marseille (e.g. `75101`).                                                                                                                                                        |
| venue_municipality_code   |           | INSEE code of the municipality (commune) where the venue is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `venue_city_code` everywhere else.                                                       |
| venue_municipality_label  |           | Name of the municipality (commune) of `venue_municipality_code` (e.g. `Paris` for every Paris arrondissement).                                                                                                                                                                      |
| offerer_is_epn            |           | Boolean true when the offerer carries the backoffice tag 'part-epn' (EPN: Établissement Public National).                                                                                                                                                                           |
| offer_category_id         |           | Identifier of the offer category, which groups offer subcategories (offer_subcategory_id): the cultural partner picks the subcategory from a predefined list when creating the offer, and the category follows from it. Rows of retired subcategories can carry a retired category. |
| total_bookings            |           | Total number of bookings, both individual and collective.                                                                                                                                                                                                                           |
| total_quantities          |           | Number of seats booked: the sum of booking quantities, where a duo booking counts 2. Not a number of bookings.                                                                                                                                                                      |
| total_revenue_amount      |           | Revenue: sum of booking_intermediary_amount of used individual bookings that have an invoiced pricing included in a payment batch, at the row's grain.                                                                                                                              |
| total_reimbursed_amount   |           | Amount reimbursed by pass Culture to offerers at the row's grain: pricing amounts on 'offerer revenue' pricing lines of invoiced pricings in a payment batch.                                                                                                                       |
| total_contribution_amount |           | Total amount contributed by the offerers on their bookings, i.e. the share of revenue borne by the offerers (revenue minus reimbursed amount): 'offerer contribution' pricing lines of invoiced pricings in a payment batch, at the row's grain.                                    |
