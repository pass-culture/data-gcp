# Table: Product

The `mrt_global__product` table is the product catalog: one row per product, the reference record that synchronized offers point to through `offer_product_id`. Products come from providers — Titelive for paper books, CDs and vinyls (keyed by EAN), cinema providers for movies (keyed by Allociné id) — and several offers, from different venues, can share one product.

The provider metadata (author, publisher, label, release date, price, GTL genre, movie runtime…) is extracted from the product's JSON into columns; the raw JSON is not exposed. Offer and booking counts are aggregated from the offers linked to the product.

## Table description

| name                                            | data_type | description                                                                                                                                                                             |
| ----------------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| product_id                                      | STRING    | Unique identifier of the product. Offers point to it through `offer_product_id`.                                                                                                        |
| product_ean                                     | STRING    | EAN-13 of the product, unique across products; NULL for cinema products. Offers carry the same code in `isbn`.                                                                          |
| product_name                                    | STRING    | Title of the product as received from its provider (book, album or movie title).                                                                                                        |
| product_description                             | STRING    | Summary of the product as received from its provider.                                                                                                                                   |
| product_subcategory_id                          | STRING    | Subcategory of the product: `LIVRE_PAPIER`, `SUPPORT_PHYSIQUE_MUSIQUE_CD`, `SUPPORT_PHYSIQUE_MUSIQUE_VINYLE` or `SEANCE_CINE`. Offers linked to the product carry the same subcategory. |
| product_category_id                             | STRING    | Category of the product, derived from its subcategory (`LIVRE`, `MUSIQUE_ENREGISTREE`, `CINEMA`).                                                                                       |
| product_last_provider_id                        | STRING    | Identifier of the provider that last updated the product (Titelive for books and music, cinema providers for movies).                                                                   |
| product_last_provider_name                      | STRING    | Name of the provider that last updated the product.                                                                                                                                     |
| product_modified_at_last_provider_date          | DATETIME  | Datetime of the product's last update by its provider.                                                                                                                                  |
| product_has_image                               | BOOLEAN   | True when the product has at least one image (thumb).                                                                                                                                   |
| product_author                                  | STRING    | Author of the product (a book's author, an album's main artist), from the provider's metadata.                                                                                          |
| product_performer                               | STRING    | Performer of a music product, from the provider's metadata.                                                                                                                             |
| product_publisher                               | STRING    | Publisher (`editeur`) of a book or music product, from the provider's metadata.                                                                                                         |
| product_music_label                             | STRING    | Record label of a music product, from the provider's metadata.                                                                                                                          |
| product_distributor                             | STRING    | Distributor of a book or music product, from the provider's metadata.                                                                                                                   |
| product_collection                              | STRING    | Collection a book belongs to, from the provider's metadata.                                                                                                                             |
| product_book_format                             | STRING    | Format of a book as sent by Titelive (for example `POCHE`, `REVUE`, `BEAUX LIVRES`); NULL when Titelive sends none.                                                                     |
| product_language_iso                            | STRING    | ISO 639-2 language code of a book (for example `fra`, `eng`), from the provider's metadata.                                                                                             |
| product_clil_code                               | STRING    | CLIL code of a book (the French book trade's subject classification), from the provider's metadata.                                                                                     |
| product_rayon                                   | STRING    | Titelive shelf (`rayon`) of a book.                                                                                                                                                     |
| product_release_date                            | DATE      | Release date of the product: publication date for books and music (`date_parution`, sent as `YYYY-MM-DD` or `DD/MM/YYYY`), release date for movies. NULL when the provider sends none.  |
| product_price                                   | NUMERIC   | Public price in euros sent by the provider (`prix_livre` for books, `prix_musique` for music); not the price of any offer.                                                              |
| product_gtl_id                                  | STRING    | Genre Tite Live (GTL) identifier of a book or music product, as sent by Titelive. Labels come from the GTL reference; an id absent from it leaves the labels NULL.                      |
| gtl_type                                        | STRING    | Type of GTL associated to this offer. Can either be "BOOK" or "MUSIC". Can be NULL.                                                                                                     |
| gtl_label_level_1                               | STRING    | Name of the level 1 GTL associated to this offer (for example, "Littératurefor a                                                                                                        |
|                                                 |           | book or "Pop" for music.)                                                                                                                                                               |
| gtl_label_level_2                               | STRING    | Name of the level 2 GTL associated to this offer (for example, "Poésie" for a book                                                                                                      |
|                                                 |           | or "Brit Pop" for music.)                                                                                                                                                               |
| gtl_label_level_3                               | STRING    | Name of the level 3 GTL associated to this offer (for example, "Haiku" for a book).                                                                                                     |
|                                                 |           | Only available for books.                                                                                                                                                               |
| gtl_label_level_4                               | STRING    | Name of the level 4 GTL associated to this offer. Only available for books.                                                                                                             |
| product_allocine_id                             | STRING    | Allociné identifier of a cinema product.                                                                                                                                                |
| product_movie_visa                              | STRING    | Exploitation visa number of a movie (CNC).                                                                                                                                              |
| product_movie_runtime                           | INT64     | Runtime of a movie, in minutes.                                                                                                                                                         |
| product_movie_production_year                   | INT64     | Production year of a movie.                                                                                                                                                             |
| product_first_offer_creation_date               | DATE      | Creation date of the first offer linked to the product.                                                                                                                                 |
| product_total_offers                            | INT64     | Number of offers linked to the product (`offer_product_id`), whatever their status.                                                                                                     |
| product_total_bookable_offers                   | INT64     | Number of offers linked to the product that are currently bookable.                                                                                                                     |
| product_total_venues                            | INT64     | Number of distinct venues with at least one offer linked to the product.                                                                                                                |
| product_total_individual_bookings               | INT64     | Number of individual bookings on the offers linked to the product, cancelled bookings included.                                                                                         |
| product_total_non_cancelled_individual_bookings | INT64     | Number of individual bookings on the offers linked to the product, cancelled bookings excluded.                                                                                         |
