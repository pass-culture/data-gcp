The `mrt_native__daily_offer_consultation` table aggregates offer-consultation events (`ConsultOffer`, `ConsultWholeOffer`, `ConsultDescriptionDetails`) by day, offer, traffic attribution, discovery module and user role/age, with `cnt_events` as the count of matching events.

It is used to analyse consultation volumes at the offer/offerer/venue level over time, broken down by acquisition channel (`origin`, `traffic_medium`, `traffic_campaign`), discovery module (`name`), and the consulting user's beneficiary status and age at the time of the event.

## Table description

| name             | data_type | description                                                                                                                                                                                                                                 |
| ---------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| event_date       |           | The date when the event occurred, used for partitioning the data.                                                                                                                                                                           |
| offerer_id       |           | Unique identifier of the offerer.                                                                                                                                                                                                           |
| offerer_name     |           | Name of the offerer.                                                                                                                                                                                                                        |
| venue_id         |           | Unique identifier for the venue.                                                                                                                                                                                                            |
| venue_name       |           | Name of the venue.                                                                                                                                                                                                                          |
| offer_id         |           | Unique identifier for the offer.                                                                                                                                                                                                            |
| offer_name       |           | Name of the offer as it appears in the application.                                                                                                                                                                                         |
| name             |           | Name of the Algolia/home module tag associated with the consultation, when the consultation originated from a tagged module. Null otherwise.                                                                                                |
| event_name       |           | The name of the event. For screen views, it concatenates the event name with the Firebase screen name.                                                                                                                                      |
| traffic_medium   |           | The medium of the marketing campaign (email, push notification ...)that generated the session.                                                                                                                                              |
| traffic_campaign |           | The name of the marketing campaign that generated the session.                                                                                                                                                                              |
| origin           |           | The origin of the event, indicating where it was triggered from.                                                                                                                                                                            |
| user_role        |           | Role of the user at the time of the event, derived from their deposit status: 'Bénéficiaire' (has an active deposit), 'Ancien bénéficiaire' (deposit expired), 'Non bénéficiaire' (logged in, no deposit), or 'Non loggué' (not logged in). |
| user_age         |           | Age of the user at the time of the event, computed from their birth date and the event date.                                                                                                                                                |
| cnt_events       |           | Number of consultation events matching this row's dimensions (event date, offer, origin, traffic attribution, user role/age).                                                                                                               |
