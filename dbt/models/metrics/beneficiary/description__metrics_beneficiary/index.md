The `metrics_beneficiary` model provides aggregated key indicators related to pass Culture beneficaries. It is designed to be the central model providing beneficiaries indicators for export, monitoring and gouvernance.

## Table Description

Each row represents a key indicator calculated for a specific month, geographic aggregation and beneficiary dimensions level.

| name                          | data_type | description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month               |           | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| region_name                   |           | The official name of the region containing the IRIS area.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| region_code                   |           | The official code of the region (région) containing the IRIS area.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| department_name               |           | The official name of the department containing the IRIS area.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| department_code               |           | The official code of the department (département) containing the IRIS area.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| epci_name                     |           | Name of the EPCI (Établissement Public de Coopération Intercommunale) of the user's registered address; 'non localisé' when not located. It reflects the user's last known address (geocoded in a full pass in February–March 2025, then re-geocoded as users change address), not necessarily their current residence.                                                                                                                                                                                    |
| epci_code                     |           | Code of the EPCI (Etablissement Public de Cooperation Intercommunale) where the user is located.                                                                                                                                                                                                                                                                                                                                                                                                           |
| city_name                     |           | Name of the city associated with the user's registered address, at the arrondissement level for Paris, Lyon and Marseille (e.g. `Paris 1er Arrondissement`).                                                                                                                                                                                                                                                                                                                                               |
| city_code                     |           | INSEE code of the city associated with the user's registered address, at the arrondissement level for Paris, Lyon and Marseille (e.g. `75101`).                                                                                                                                                                                                                                                                                                                                                            |
| municipality_label            |           | Name of the municipality (commune) of `user_municipality_code` (e.g. `Paris` for every Paris arrondissement).                                                                                                                                                                                                                                                                                                                                                                                              |
| municipality_code             |           | The official INSEE code of the municipality (*commune*) the IRIS belongs to: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the municipality itself everywhere else. This is the level at which INSEE publishes municipal data (population, EPCI, density grid, zonings), so it is the code to join a municipality referential on — unlike `city_code`, which goes down to the arrondissement. Not a postal code.                               |
| age_at_calculation            |           | The user's age calculated at the specific reference date of the record (usually the end of the month). Unlike the current age, this value reflects the user's age at the historical point in time represented by the row.                                                                                                                                                                                                                                                                                  |
| is_in_qpv                     |           | Boolean. TRUE when the user's geocoded address falls inside a priority neighbourhood (QPV). Membership is computed on the geocoded address, not derived from the IRIS: one IRIS can mix addresses in and out of QPVs.                                                                                                                                                                                                                                                                                      |
| macro_density_label           |           | Two-class density of the user's registered address, derived from the INSEE municipal density grid: 'urbain' (levels 1 to 4), 'rural' (levels 5 to 7), or 'non localisé' when the address cannot be attached to a municipality. It reflects the user's last known address (geocoded in a full pass in February–March 2025, then re-geocoded as users change address), not necessarily their current residence.                                                                                              |
| micro_density_label           |           | String column. Label of the INSEE municipal density grid (grille communale de densité, 7 levels) of the municipality of the user's registered address; 'non localisé' when not located. It reflects the user's last known address (geocoded in a full pass in February–March 2025, then re-geocoded as users change address), not necessarily their current residence.                                                                                                                                     |
| total_actual_beneficiaries    |           | The total count of active beneficiaries at the time of calculation. To be included, a user must have a non-expired credit and a remaining amount of credit available for booking.                                                                                                                                                                                                                                                                                                                          |
| total_beneficiaries           |           | Number of beneficiaries at the end of the partition month, broken down by `age_at_calculation`. Counts every user with an active account (or suspended upon user request) who has ever received credit, regardless of whether the credit is currently active, exhausted, or expired. A user's `age_at_calculation` is recomputed each month, so the same user can appear in different age buckets across partition_months. Not a true running total — users with deactivated accounts drop from the count. |
| cell_key_beneficiaries        |           | Cell key (0-255) of the matching count, used to perturb that count on publication (statistical disclosure control, cell key method): the salted record keys of the counted users summed modulo 256. Neither a measure nor a dimension: do not display it. When rows are aggregated, the key of the aggregate is mod(abs(sum(cell_key)), 256), not the plain sum.                                                                                                                                           |
| cell_key_actual_beneficiaries |           | Cell key (0-255) of the matching count, used to perturb that count on publication (statistical disclosure control, cell key method): the salted record keys of the counted users summed modulo 256. Neither a measure nor a dimension: do not display it. When rows are aggregated, the key of the aggregate is mod(abs(sum(cell_key)), 256), not the plain sum.                                                                                                                                           |
