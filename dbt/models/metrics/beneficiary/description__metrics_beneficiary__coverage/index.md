The `metrics_beneficiary__coverage` model provides aggregated key indicators related to pass Culture beneficary coverage. It is designed to be the central model providing beneficiary coverage indicators for export, monitoring and gouvernance.

## Table Description

Each row represents a key indicator calculated for a specific month, geographic aggregation and beneficiary dimensions level.

| name                               | data_type | description                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                    |           | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                                                                                                                                        |
| region_name                        |           | The official name of the region containing the IRIS area.                                                                                                                                                                                                                                                                                                                                      |
| region_code                        |           | The official code of the region (région) containing the IRIS area.                                                                                                                                                                                                                                                                                                                             |
| department_name                    |           | The official name of the department containing the IRIS area.                                                                                                                                                                                                                                                                                                                                  |
| department_code                    |           | The official code of the department (département) containing the IRIS area.                                                                                                                                                                                                                                                                                                                    |
| milestone_age                      |           | Age milestone in whole years, used to determine users eligibility: months between birth month and the observation month divided by 12, kept when it is an integer, so milestone_age N is the cohort turning N that month. Stored as INT64 in beneficiary coverage models and in exp_vidoc\_\_population_coverage, STRING in int_kpi\_\_population_coverage and metrics_population\_\_coverage. |
| total_beneficiaries_last_12_months |           | Rolling sum of distinct users over the last 12 months for a given age and department: the sum of monthly distinct-user counts over the current and 11 previous months, so a user active in several months is counted once per month.                                                                                                                                                           |
| cell_key_beneficiaries             | INT64     | Cell key (0-255) of the matching count, used to perturb that count on publication (statistical disclosure control, cell key method): the salted record keys of the counted users summed modulo 256. Neither a measure nor a dimension: do not display it. When rows are aggregated, the key of the aggregate is mod(abs(sum(cell_key)), 256), not the plain sum.                               |
