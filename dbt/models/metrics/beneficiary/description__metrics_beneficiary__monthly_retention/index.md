The `metrics_beneficiary__monthly_retention` model provides aggregated key indicators related to pass Culture beneficiary connection rates, active usage, and retention metrics, computed on a monthly basis.

It consolidates data from connection tracking (eligible vs. connected users) and engagement tracking (MAU, DAU, and stickiness ratio) to offer a unified overview of user engagement across different deposit reform categories.

## Table Description

Each row represents monthly aggregated retention and connection metrics for a specific activity month and deposit reform category.

| name                         | data_type | description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| activity_month               |           | The month during which the connection and engagement metrics are measured (format: YYYY-MM-01).                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| deposit_reform_category      |           | Categorizes deposits relative to the March 2025 reform: pre-reform ('15_17_pre_reform' for GRANT_15_17, '18_pre_reform' and '18_experiment_phase' for GRANT_18 up to or above €300) vs post-reform ('17_post_reform' and '18_post_reform' for GRANT_17_18, '15_16_post_reform' for GRANT_FREE). For GRANT_17_18 it carries only the LATEST stage: a deposit created at 17 and recredited at 18 is '18_post_reform', so '17_post_reform' misses about a third of 17-credit recipients; read RECREDIT_17 / RECREDIT_18 in the recredit table instead. |
| total_mau                    |           | Total Monthly Active Users (MAU): the count of unique beneficiaries who visited the platform during the month.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| avg_dau                      |           | Average Daily Active Users (DAU): the average number of unique active beneficiaries per day over the course of the month.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| pct_stickiness_dau_mau_ratio |           | User stickiness ratio calculated as `(avg_dau / total_mau)`, representing how frequently monthly active users return to the platform on a daily basis.                                                                                                                                                                                                                                                                                                                                                                                              |
| total_eligible_users         |           | Total number of beneficiaries eligible with at least 5 euros remaining credit to connect and use their pass Culture credit during the month.                                                                                                                                                                                                                                                                                                                                                                                                        |
| total_connected_users        |           | Total number of eligible beneficiaries who successfully logged in or connected to the platform at least once during the month.                                                                                                                                                                                                                                                                                                                                                                                                                      |
| pct_connected_users          | FLOAT64   | Share of eligible beneficiaries who connected to the platform during the month (`total_connected_users / total_eligible_users`), as a ratio between 0 and 1 (not multiplied by 100).                                                                                                                                                                                                                                                                                                                                                                |
