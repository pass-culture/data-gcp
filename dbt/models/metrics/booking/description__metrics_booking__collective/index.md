The `metrics_booking__collective` model provides collective booking indicators by month, school year and **venue** geography (pre-reservations, confirmed bookings, confirmations, actions; monthly and school year to date). It is the central model for collective booking indicators by cultural partner location, for export, monitoring and governance. See [`int_kpi__booking_collective`](#!/model/model.data_gcp_dbt.int_kpi__booking_collective) for the rules.

## Table Description

Each row represents the key indicators related to collective bookings, calculated for a specific month, school year and venue geographic level (department / region / city / EPCI).

| name                                     | data_type | description                                                                                                                                                                                                                        |
| ---------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                          | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                            |
| scholar_year                             | STRING    | Scholar year of the deposit.                                                                                                                                                                                                       |
| venue_region_name                        | STRING    | Region name where the venue is located.                                                                                                                                                                                            |
| venue_region_code                        | STRING    | Region code where the venue is located.                                                                                                                                                                                            |
| venue_academy_name                       | STRING    | Academy of the venue.                                                                                                                                                                                                              |
| venue_department_name                    | STRING    | Department name where of the venue.                                                                                                                                                                                                |
| venue_department_code                    | STRING    | Department code of the venue.                                                                                                                                                                                                      |
| venue_epci_name                          | STRING    | EPCI name of the venue.                                                                                                                                                                                                            |
| venue_epci_code                          | STRING    | EPCI code of the venue.                                                                                                                                                                                                            |
| venue_city_name                          | STRING    | Name of the city where the venue is located, at the arrondissement level for Paris, Lyon and Marseille (e.g. `Paris 1er Arrondissement`).                                                                                          |
| venue_city_code                          | STRING    | INSEE code of the city where the venue is located, at the arrondissement level for Paris, Lyon and Marseille (e.g. `75101`).                                                                                                       |
| venue_municipality_label                 | STRING    | Name of the municipality (commune) of `venue_municipality_code` (e.g. `Paris` for every Paris arrondissement).                                                                                                                     |
| venue_municipality_code                  | STRING    | INSEE code of the municipality (commune) where the venue is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `venue_city_code` everywhere else.      |
| venue_macro_density_label                | STRING    | Macro density label of the venue's location (urbain, rural)                                                                                                                                                                        |
| total_prereservations                    | INTEGER   | Number of non-cancelled collective bookings (pre-reservations, whatever their status) created in the month. A booking created before its scholar year starts is counted in the first month of that scholar year.                   |
| total_prereservation_amount              | FLOAT     | Amount of the non-cancelled collective bookings created in the month (same attribution as `total_prereservations`).                                                                                                                |
| total_collective_bookings                | INTEGER   | Number of collective bookings created in the month that are confirmed (confirmed, used, pending reimbursement or reimbursed). A booking created before its scholar year starts is counted in the first month of that scholar year. |
| total_collective_amount_spent            | FLOAT     | Total amount spent for collective bookings.                                                                                                                                                                                        |
| total_confirmations                      | INTEGER   | Number of collective bookings confirmed by the school head in the month (by confirmation date, clamped into the booking's scholar year).                                                                                           |
| total_confirmation_amount                | FLOAT     | Amount of the collective bookings confirmed in the month.                                                                                                                                                                          |
| total_actions                            | INTEGER   | Number of confirmed collective bookings whose action (stock beginning date) takes place in the month. Future months give a forecast.                                                                                               |
| total_action_amount                      | FLOAT     | Amount of the confirmed collective bookings whose action takes place in the month.                                                                                                                                                 |
| cumulative_total_prereservations         | INTEGER   | `total_prereservations` summed from the start of the scholar year up to and including the month.                                                                                                                                   |
| cumulative_total_prereservation_amount   | FLOAT     | `total_prereservation_amount` summed from the start of the scholar year up to and including the month.                                                                                                                             |
| cumulative_total_collective_bookings     | INTEGER   | Cumulative total number of collective bookings for the same geography from the start of the given school year up to and including the specified month.                                                                             |
| cumulative_total_collective_amount_spent | FLOAT     | Cumulative total amount spent for collective bookings for the same geography from the start of the given school year up to and including the specified month.                                                                      |
| cumulative_total_confirmations           | INTEGER   | `total_confirmations` summed from the start of the scholar year up to and including the month.                                                                                                                                     |
| cumulative_total_confirmation_amount     | FLOAT     | `total_confirmation_amount` summed from the start of the scholar year up to and including the month.                                                                                                                               |
| cumulative_total_actions                 | INTEGER   | `total_actions` summed from the start of the scholar year up to and including the month.                                                                                                                                           |
| cumulative_total_action_amount           | FLOAT     | `total_action_amount` summed from the start of the scholar year up to and including the month.                                                                                                                                     |
