The `metrics_booking__collective_by_domain` model provides aggregated key indicators related to collective bookings by educational domain and institution geography. It is designed to be the central model providing collective booking indicators broken down by cultural domain for export, monitoring and governance.

## Table Description

Each row represents the key indicators related to collective bookings, calculated for a specific month, educational domain and institution geographic level (department / region / city / EPCI).

| name                                       | data_type | description                                                                                                                                                                                                        |
| ------------------------------------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| partition_month                            | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                            |
| scholar_year                               | STRING    | Scholar year of the deposit.                                                                                                                                                                                       |
| educational_domain_name                    | STRING    | Unique name corresponding to the id of the educational domain of the collective offer or venue.                                                                                                                    |
| institution_region_name                    | STRING    | Region name of the educational institution.                                                                                                                                                                        |
| institution_region_code                    | STRING    | INSEE region code of the educational institution, derived from the department code via the region_department seed. Defaults to '-1' when not found.                                                                |
| institution_department_name                | STRING    | Department name of the educational institution.                                                                                                                                                                    |
| institution_department_code                | STRING    | Department code of the educational institution.                                                                                                                                                                    |
| institution_epci_name                      | STRING    | EPCI name of the educational institution.                                                                                                                                                                          |
| institution_epci_code                      | STRING    | EPCI code of the educational institution.                                                                                                                                                                          |
| institution_city_code                      | STRING    | City code where the educational institution is located.                                                                                                                                                            |
| total_collective_bookings                  | INTEGER   | Total number of collective bookings.                                                                                                                                                                               |
| total_collective_booking_amount            | FLOAT     | Total amount generated by the bookings.                                                                                                                                                                            |
| total_collective_tickets                   | INTEGER   | The total number of tickets for the educational institution.                                                                                                                                                       |
| total_collective_institutions              | INTEGER   | Total number of distinct educational institutions that made at least one collective booking.                                                                                                                       |
| cumulative_total_collective_bookings       | INTEGER   | Cumulative total number of EAC collective bookings for the same institution geography and domain from the beginning of the data history up to and including the specified month.                                   |
| cumulative_total_collective_booking_amount | FLOAT     | Cumulative total booking amount for EAC collective bookings for the same institution geography and domain from the beginning of the data history up to and including the specified month.                          |
| cumulative_total_collective_tickets        | INTEGER   | Cumulative total number of tickets generated for EAC collective bookings for the same institution geography and domain from the beginning of the data history up to and including the specified month.             |
| cumulative_total_collective_institutions   | INTEGER   | Cumulative total number of distinct educational institutions involved in EAC collective bookings for the same geography and domain from the beginning of the data history up to and including the specified month. |
