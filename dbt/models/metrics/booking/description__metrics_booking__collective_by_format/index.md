The `metrics_booking__collective_by_format` model provides aggregated key indicators related to collective bookings by offer format and institution geography. It is designed to be the central model providing collective booking indicators broken down by offer format for export, monitoring and governance.

## Table Description

Each row represents the key indicators related to collective bookings, calculated for a specific month, offer format and institution geographic level (academy / department / region / city / EPCI).

| name                                       | data_type | description                                                                                                                                                                                                                                           |
| ------------------------------------------ | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                            | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                               |
| scholar_year                               | STRING    | Scholar year of the deposit.                                                                                                                                                                                                                          |
| collective_offer_format                    | STRING    | One cultural format of the booked collective offer (e.g. REPRESENTATION, ATELIER_DE_PRATIQUE). An offer with several formats counts in each of them, so formats are not summable.                                                                     |
| institution_region_name                    | STRING    | Region name of the educational institution.                                                                                                                                                                                                           |
| institution_region_code                    | STRING    | INSEE region code of the educational institution, derived from the department code via the region_department seed. Defaults to '-1' when not found.                                                                                                   |
| institution_academy_name                   | STRING    | Academy name of the educational institution.                                                                                                                                                                                                          |
| institution_department_name                | STRING    | Department name of the educational institution.                                                                                                                                                                                                       |
| institution_department_code                | STRING    | Department code of the educational institution.                                                                                                                                                                                                       |
| institution_epci_name                      | STRING    | EPCI name of the educational institution.                                                                                                                                                                                                             |
| institution_epci_code                      | STRING    | EPCI code of the educational institution.                                                                                                                                                                                                             |
| institution_city_code                      | STRING    | INSEE code of the city where the educational institution is located, at the arrondissement level for Paris, Lyon and Marseille (e.g. `75101`).                                                                                                        |
| institution_municipality_code              | STRING    | INSEE code of the municipality (commune) where the educational institution is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `institution_city_code` everywhere else. |
| total_collective_bookings                  | INTEGER   | Number of collective bookings created in the month that are confirmed (confirmed, used, pending reimbursement or reimbursed). A booking created before its scholar year starts is counted in the first month of that scholar year.                    |
| total_collective_booking_amount            | FLOAT     | Total amount generated by the bookings.                                                                                                                                                                                                               |
| total_collective_tickets                   | INTEGER   | The total number of tickets for the educational institution.                                                                                                                                                                                          |
| total_collective_institutions              | INTEGER   | Total number of distinct educational institutions that made at least one collective booking.                                                                                                                                                          |
| cumulative_total_collective_bookings       | INTEGER   | Cumulative total number of EAC collective bookings for the same institution geography and offer format from the start of the scholar year up to and including the specified month.                                                                    |
| cumulative_total_collective_booking_amount | FLOAT     | Cumulative total booking amount for EAC collective bookings for the same institution geography and offer format from the start of the scholar year up to and including the specified month.                                                           |
| cumulative_total_collective_tickets        | INTEGER   | Cumulative total number of tickets generated for EAC collective bookings for the same institution geography and offer format from the start of the scholar year up to and including the specified month.                                              |
| cumulative_total_collective_institutions   | INTEGER   | Number of distinct educational institutions with at least one EAC collective booking in the offer format since the start of the scholar year, up to and including the specified month (each institution counted once).                                |
