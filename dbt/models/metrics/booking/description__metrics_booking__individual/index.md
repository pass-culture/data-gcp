The `metrics_booking__individual` model provides individual booking indicators by month, **beneficiary** geography, **venue** geography and offer category: used bookings and amounts by month of use, all and free bookings (cancelled included) by month of creation. It is the central model for individual booking indicators, for export, monitoring and governance. See [`int_kpi__booking_individual`](#!/model/model.data_gcp_dbt.int_kpi__booking_individual) for the rules.

## Table Description

Each row represents the individual booking flows of a month for a beneficiary municipality, a venue municipality and an offer category.

| name                        | data_type | description                                                                                                                                                                                                                                                                         |
| --------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month             | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                             |
| user_is_beneficiary         | BOOLEAN   | True when the user who booked is in `mrt_global__user_beneficiary` (active or suspended upon his own request, and not on a GRANT_FREE deposit). False for deleted, suspended and GRANT_FREE users: their bookings are kept, without beneficiary geography.                          |
| region_name                 | STRING    | Region name of the user's registered address.                                                                                                                                                                                                                                       |
| department_name             | STRING    | Department name associated with the user's registered address.                                                                                                                                                                                                                      |
| epci_code                   | STRING    | Code of the EPCI (Etablissement Public de Cooperation Intercommunale) where the user is located.                                                                                                                                                                                    |
| municipality_code           | STRING    | INSEE code of the municipality (commune) associated with the user's registered address: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `user_city_code` everywhere else.                                     |
| venue_region_name           | STRING    | Region name where the venue is located.                                                                                                                                                                                                                                             |
| venue_department_name       | STRING    | Department name where of the venue.                                                                                                                                                                                                                                                 |
| venue_epci_code             | STRING    | EPCI code of the venue.                                                                                                                                                                                                                                                             |
| venue_municipality_code     | STRING    | INSEE code of the municipality (commune) where the venue is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `venue_city_code` everywhere else.                                                       |
| offer_category_id           | STRING    | Identifier of the offer category, which groups offer subcategories (offer_subcategory_id): the cultural partner picks the subcategory from a predefined list when creating the offer, and the category follows from it. Rows of retired subcategories can carry a retired category. |
| total_used_bookings         | INTEGER   | Number of used individual bookings (booking_is_used), counted on the month of use, for the row's cell.                                                                                                                                                                              |
| total_used_amount           | NUMERIC   | Amount of the used individual bookings (booking_intermediary_amount, in euros), counted on the month of use, for the row's cell.                                                                                                                                                    |
| total_created_bookings      | INTEGER   | Number of individual bookings created in the month, in any state (cancelled included), for the row's cell.                                                                                                                                                                          |
| total_created_free_bookings | INTEGER   | Number of free individual bookings (booking_amount = 0) created in the month, in any state (cancelled included), for the row's cell. Free bookings are often cancelled by default as they need no check.                                                                            |
