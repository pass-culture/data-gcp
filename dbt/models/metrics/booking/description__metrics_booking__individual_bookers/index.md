The `metrics_booking__individual_bookers` model provides the new bookers (first used booking since January 2022) by month, **beneficiary** geography and offer category. Summed over months, they give the distinct bookers of any territory since 2022. See [`int_kpi__booking_individual_bookers`](#!/model/model.data_gcp_dbt.int_kpi__booking_individual_bookers) for the rules.

## Table Description

Each row represents the new bookers of a month for a beneficiary municipality and an offer category.

| name                       | data_type | description                                                                                                                                                                                                                                                                           |
| -------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month            | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                                                               |
| region_name                | STRING    | Region name of the user's registered address.                                                                                                                                                                                                                                         |
| department_name            | STRING    | Department name associated with the user's registered address.                                                                                                                                                                                                                        |
| epci_code                  | STRING    | Code of the EPCI (Etablissement Public de Cooperation Intercommunale) where the user is located.                                                                                                                                                                                      |
| municipality_code          | STRING    | INSEE code of the municipality (commune) associated with the user's registered address: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `user_city_code` everywhere else.                                       |
| offer_category_id          | STRING    | Identifier of the offer category, which groups offer subcategories (offer_subcategory_id): the cultural partner picks the subcategory from a predefined list when creating the offer, and the category follows from it. Rows of retired subcategories can carry a retired category.   |
| total_new_bookers          | INTEGER   | Number of beneficiaries whose first used booking since January 2022 is in the month, all categories. Each beneficiary is counted once, on the row of the category of that first booking: sum the categories and the months to get the distinct bookers of a territory since 2022.     |
| total_new_category_bookers | INTEGER   | Number of beneficiaries whose first used booking since January 2022 in the row's offer category is in the month: sum the months to get the distinct bookers of a category in a territory since 2022. Do not sum the categories (a beneficiary is counted in each category he booked). |
