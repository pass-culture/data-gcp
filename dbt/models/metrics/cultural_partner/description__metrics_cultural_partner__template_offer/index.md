The `metrics_cultural_partner__template_offer` model provides the number of cultural partners (venues) with a collective template offer ("offre vitrine") by month and **partner** geography (new partners in the month and cumulative stock). It is the central model for this indicator, for export, monitoring and governance. See [`int_kpi__cultural_partner_template_offer`](#!/model/model.data_gcp_dbt.int_kpi__cultural_partner_template_offer) for the rules.

## Table Description

Each row represents the template offer indicators of the cultural partners of a geography (region / department / EPCI / city) for a specific month.

| name                                          | data_type | description                                                                                                                                                                                                                                |
| --------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| partition_month                               | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                                    |
| partner_region_name                           | STRING    | Name of the region where the cultural partner is located.                                                                                                                                                                                  |
| partner_region_code                           | STRING    | Code of the region where the cultural partner is located.                                                                                                                                                                                  |
| partner_academy_name                          | STRING    | Name of the academy associated with the cultural partner.                                                                                                                                                                                  |
| partner_department_name                       | STRING    | Name of the department where the cultural partner is located.                                                                                                                                                                              |
| partner_department_code                       | STRING    | Code of the department where the cultural partner is located.                                                                                                                                                                              |
| partner_epci_code                             | STRING    | Code of the EPCI where the cultural partner is located.                                                                                                                                                                                    |
| partner_city_code                             | STRING    | INSEE code of the city where the cultural partner is located, at the arrondissement level for Paris, Lyon and Marseille (e.g. `75101`).                                                                                                    |
| partner_municipality_code                     | STRING    | INSEE code of the municipality (commune) where the cultural partner is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `partner_city_code` everywhere else. |
| total_new_partners_with_template_offer        | INT64     | Number of distinct partners (venues) whose first collective template offer ("offre vitrine") was created during the month. Monthly flow.                                                                                                   |
| total_cumulative_partners_with_template_offer | INT64     | Number of distinct partners (venues) that have created at least one collective template offer ("offre vitrine") up to the end of the month. Stock, do not sum over months.                                                                 |
