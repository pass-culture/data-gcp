The `metrics_diversity__by_category` model aggregates key performance indicators to quantify diversity within beneficiary bookings on the pass Culture app, for each offer categories. It is designed to be the central model providing beneficiary diversity indicators for export, monitoring and gouvernance.

## Table Description

Each row represents a key indicator calculated for a specific month, geographic aggregation, offer category and beneficiary dimensions level.
