The `metrics_offer__individual_free` model provides the free individual offers (last stock price 0) by creation month and **venue** geography, monthly and cumulative since the first free offer of the territory. See [`int_kpi__offer_individual_free`](#!/model/model.data_gcp_dbt.int_kpi__offer_individual_free) for the rules.

## Table Description

Each row represents the free offers of a month for a venue municipality.

| name                                          | data_type | description                                                                                                                                                                                                                   |
| --------------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| partition_month                               | DATE      | Indicates the first day of the month the KPI refers to.                                                                                                                                                                       |
| venue_region_name                             | STRING    | Region name where the venue is located.                                                                                                                                                                                       |
| venue_department_name                         | STRING    | Department name where of the venue.                                                                                                                                                                                           |
| venue_epci_code                               | STRING    | EPCI code of the venue.                                                                                                                                                                                                       |
| venue_municipality_code                       | STRING    | INSEE code of the municipality (commune) where the venue is located: the parent municipality for the arrondissements of Paris, Lyon and Marseille (`75056`, `69123`, `13055`), the same as `venue_city_code` everywhere else. |
| total_created_free_offers                     | INTEGER   | Number of free individual offers (last stock price 0) created in the month, in any state.                                                                                                                                     |
| total_created_free_bookable_offers            | INTEGER   | Number of free individual offers (last stock price 0) created in the month that are bookable today.                                                                                                                           |
| cumulative_total_created_free_offers          | INTEGER   | Number of free individual offers (last stock price 0) of the territory created up to and including the month, in any state.                                                                                                   |
| cumulative_total_created_free_bookable_offers | INTEGER   | Number of free individual offers (last stock price 0) of the territory created up to and including the month that are bookable today.                                                                                         |
