## VIDOC exports

VIDOC is the Ministry of Culture dashboard. pass Culture feeds it with the `exp_vidoc__*` tables (BigQuery dataset `export_vidoc_{env}`). The lot 1 tables are also sent to the ministry S3 bucket by the `export_vidoc` DAG, which only sends the lot 1 columns.

The KPIs computed from these tables are defined in [KPIs](https://pass-culture.github.io/data-gcp/dbt/kpis/index.md).

### Open data

The lot 1 beneficiary and diversity tables are also published as open data on [data.gouv.fr](https://pass-culture.github.io/data-gcp/dbt/data_gouv/index.md). Both exports read the same perturbed base (`exp_base__*`), so the open data figures are the VIDOC figures. The data.gouv.fr resources keep only the lot 1 columns and closed months, and format geographic codes for data.gouv.fr.

### Data protection

Beneficiary counts are perturbed with the cell key method; partner and finance figures follow the external reporting rules. See [Statistical confidentiality](https://pass-culture.github.io/data-gcp/dbt/references/statistical_confidentiality/index.md).
