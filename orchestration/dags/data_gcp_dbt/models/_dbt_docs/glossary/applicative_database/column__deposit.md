{% docs column__deposit_date %}The date when the deposit was made.{% enddocs %}
{% docs column__deposit_amount %}The total amount of the deposit. Amount varies by deposit_type. GRANT_15_17: 20€ in the year the user turns 15, 30€ at 16, 30€ at 17, 30€ in the year they turn 17; GRANT_18: 300€ before the reform, 500€ during the experimental phase; GRANT_17_18: 150€; GRANT_FREE: 0€ for 15–16-year-olds (allows free bookings).{% enddocs %}
{% docs column__deposit_source %} Creation source of the deposit. Possible values: educonnect – Deposit initiated via the French national education authentication system; ubble – Deposit created following a remote identity verification process via Ubble.
dms – Deposit imported from a Document Management System (internal or third-party document repository).{% enddocs %}
{% docs column__deposit_creation_date %}The date when the deposit was created.{% enddocs %}
{% docs column__deposit_active_date %} Active date of a deposit.{% enddocs %}
{% docs column__deposit_update_date %}The date when the deposit was last updated (only for GRANT_15_17).{% enddocs %}
{% docs column__deposit_expiration_date %}The expiration date of the deposit. GRANT_18: 24 months after creation; GRANT_15_17: On the user’s 18th birthday; GRANT_17_18: The day before the user turns 21.{% enddocs %}
{% docs column__deposit_type %} Type of the deposit, can be GRANT_18, GRANT_15_17, GRANT_17_18, GRANT_FREE. Since the March 2025 reform, new adult credits are issued as GRANT_17_18 (GRANT_18 is pre-reform/legacy): to measure adult-credit conversion across the reform, count GRANT_18 OR GRANT_17_18, not GRANT_18 alone. {% enddocs %}
{% docs column__deposit_reform_category %} Categorizes deposits relative to the March 2025 reform: pre-reform (15_17_pre_reform, 18_pre_reform, 18_experiment_phase) vs post-reform (17_post_reform, 18_post_reform). For GRANT_17_18 it carries only the LATEST stage of the deposit: a deposit created at 17 and recredited at 18 is 18_post_reform (99.9% of those also received the 17 credit). Do NOT count 17-credit recipients with 17_post_reform — it misses about a third of them; read the age credits in the recredit table instead (recredit_type RECREDIT_17 / RECREDIT_18 on a GRANT_17_18 deposit). {% enddocs %}
{% docs column__deposit_rank_asc %}Ascending rank of the deposit in user's history.{% enddocs %}
{% docs column__deposit_rank_desc %}Descending rank of the deposit in user's history.{% enddocs %}
{% docs column__deposit_seniority %}Total days between deposit_creation_date and today. Used for analytics purposes.{% enddocs %}
{% docs column__days_between_user_creation_and_deposit_creation %} Total days between user_creation_date (user activated its account) and deposit_creation_date (user received grant). {% enddocs %}
{% docs column__user_first_deposit_creation_date %} First deposit creation date. {% enddocs %}
{% docs column__credit_17_18 %} credit_17 / credit_18 (« crédit 17 ans » / « crédit 18 ans »): the money granted to a young person at 17 and at 18, whatever deposit carries it — not the deposit itself, nor the remaining balance. credit_17 = a RECREDIT_17 (50€ on GRANT_17_18 since the March 2025 reform, 30€ on GRANT_15_17 before), or a GRANT_15_17 deposit created at 17. credit_18 = a GRANT_18 deposit (300€, before the reform) or a RECREDIT_18 on GRANT_17_18 (150€, after). Not credits: GRANT_FREE (0€), PREVIOUS_DEPOSIT (balance carried over), BONUS_CREDIT, MANUAL_MODIFICATION. {% enddocs %}
{% docs column__first_credit_17_date %} The date the young person received credit_17 (see credit_17 / credit_18): first RECREDIT_17 on any deposit, or creation of a GRANT_15_17 at 17. Comparable across the March 2025 reform. It can fall at 18 when a GRANT_17_18 is opened at 18 (credit_17 and credit_18 the same day): bound it with `user_age_at_first_credit_17 = 17` to measure take-up at 17. Former GRANT_15_17 beneficiaries (born up to February 2010) receive it automatically on their 17th birthday: for those generations it reflects the former 15-17 scheme, not a sign-up. {% enddocs %}
{% docs column__first_credit_18_date %} The date the young person received credit_18 (see credit_17 / credit_18): GRANT_18 creation before the March 2025 reform, first RECREDIT_18 after. The column to compare 18-credit take-up across the reform. It can fall after the 19th birthday (late identity validations): bound it with `user_age_at_first_credit_18 < 19` to compare generations. {% enddocs %}
{% docs column__user_age_at_first_credit_17 %} The user's exact age on `first_credit_17_date`; null if no credit_17. {% enddocs %}
{% docs column__user_age_at_first_credit_18 %} The user's exact age on `first_credit_18_date`; null if no credit_18. Use `< 19` to give every generation the same 12-month window after the 18th birthday. {% enddocs %}
{% docs column__user_has_credit_before_18 %} Whether the user received money before their 18th birthday: a GRANT_15_17 deposit, or credit_17 before 18 (a RECREDIT_17 received at 18 alongside credit_18 does not count). GRANT_FREE (0€) does not count. The population to measure the drop-off between the 17 and 18 credits: `user_has_credit_before_18 and (first_credit_18_date is null or user_age_at_first_credit_18 >= 19)`. {% enddocs %}
