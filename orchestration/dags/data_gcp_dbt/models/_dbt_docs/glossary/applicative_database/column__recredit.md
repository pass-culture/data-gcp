{% docs column__last_recredit_date %} The most recent date on which the beneficiary received a new recredit. {% enddocs %}
{% docs column__total_recredit %} The total number of times the beneficiary received a new recredit. {% enddocs %}
{% docs column__total_recredit_amount %} Total amount recredited, in euros, across all recredit types, including age credits (RECREDIT_*), balance transferred from a previous deposit (PREVIOUS_DEPOSIT), bonus credits (BONUS_CREDIT), and manual modifications. It includes recredit_bonus_amount: do not add them together. Age recredits are already included in deposit_amount (or total_deposit_amount at user level), so total_recredit_amount must not be added to it. {% enddocs %}
{% docs column__recredit_bonus_amount %} Sum of BONUS_CREDIT recredit amounts on the deposit, in euros. Zero if there are no bonus recredits in the global deposit models; included in total_recredit_amount. This total does not distinguish the reasons for the bonus. {% enddocs %}
{% docs column__total_bonus_recredit %} Number of distinct BONUS_CREDIT recredits on the deposit. Zero if there are none in the global deposit models. Use a positive count to identify deposits with at least one bonus recredit, even when their summed amount is zero. {% enddocs %}
{% docs column__first_bonus_recredit_date %} Date of the earliest BONUS_CREDIT recredit on the deposit; null if there are none. {% enddocs %}
{% docs column__first_recredit_17_date %} The date of the first RECREDIT_17 on the deposit; null if none. Raw fact: on a GRANT_17_18 it is the 50€ credit_17, on a pre-reform GRANT_15_17 the 30€ top-up at 17. Dates are unlock dates (after identity validation), not request dates: a request made at 17 and unlocked after 18 carries RECREDIT_17 and RECREDIT_18 the same day, so a RECREDIT_17 is not always dated before 18. To count young people, use `first_credit_17_date` on mrt_global__user_beneficiary. {% enddocs %}
{% docs column__first_recredit_18_date %} The date of the first RECREDIT_18 (150€) on the deposit; null if none. Recorded on a GRANT_17_18 recredited at 18 and on one opened directly at 18. Raw fact: to count young people who received the 18 credit across the reform (GRANT_18 included), use `first_credit_18_date` on mrt_global__user_beneficiary. {% enddocs %}
