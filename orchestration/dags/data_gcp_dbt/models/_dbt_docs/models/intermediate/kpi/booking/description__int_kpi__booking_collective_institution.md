{% docs description__int_kpi__booking_collective_institution %}
Same KPIs as [`int_kpi__booking_collective`](#!/model/model.data_gcp_dbt.int_kpi__booking_collective), by
**school** geography (location of the educational institution) instead of venue geography. Use it for
school-side reporting (académies, établissements); use the venue model for the cultural partners of a territory.
{% enddocs %}
