{% docs description__int_kpi__cultural_partner_offerer_revenue %}
Monthly revenue of used bookings per offerer and venue municipality, for individual and collective bookings.

Each row represents the revenue generated by one offerer in one municipality during the month the bookings were used. Each municipality is mapped to a single EPCI and department from [`int_seed__geo_iris`](#!/model/model.data_gcp_dbt.int_seed__geo_iris) so that geographic levels nest.

It is the base of the statistical secret evaluation in [`metrics_cultural_partner__statistical_secret`](#!/model/model.data_gcp_dbt.metrics_cultural_partner__statistical_secret).
{% enddocs %}
