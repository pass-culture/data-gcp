{% docs description__int_kpi__cultural_partner_offerer_window_revenue %}
Revenue per offerer and municipality over the rolling window of `statistical_secret_window_months` months ending on `partition_month` (complete months only). Only positive revenues are kept: they define the contributors of the statistical secret rule.
{% enddocs %}
