# Table: User Statistics

The `ml_reco__user_statistics` table contains statistics about active beneficiary users, used as features for the recommendation pipeline. It includes deposit information, booking counts, engagement signals from Firebase, and the geographic centroid (latitude/longitude) of the user's subscription department derived from IRIS data.
