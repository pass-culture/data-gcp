The `metrics_booking__collective_by_domain` model provides aggregated key indicators related to collective bookings by educational domain and institution geography.
It is designed to be the central model providing collective booking indicators broken down by cultural domain for export, monitoring and governance.

{% enddocs %}

## Table Description

Each row represents the key indicators related to collective bookings, calculated for a specific month, educational domain and institution geographic level (department / region / city / EPCI).
