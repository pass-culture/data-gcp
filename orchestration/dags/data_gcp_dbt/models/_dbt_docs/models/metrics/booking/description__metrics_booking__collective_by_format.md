The `metrics_booking__collective_by_format` model provides aggregated key indicators related to collective bookings by offer format and institution geography.
It is designed to be the central model providing collective booking indicators broken down by offer format for export, monitoring and governance.

## Table Description

Each row represents the key indicators related to collective bookings, calculated for a specific month, offer format and institution geographic level (academy / department / region / city / EPCI).
