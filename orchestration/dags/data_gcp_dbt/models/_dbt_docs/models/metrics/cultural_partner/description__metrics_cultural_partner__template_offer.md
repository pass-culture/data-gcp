{% docs description__metrics_cultural_partner__template_offer %}

The `metrics_cultural_partner__template_offer` model provides the number of cultural partners (venues) with a
collective template offer ("offre vitrine") by month and **partner** geography (new partners in the month and
cumulative stock). It is the central model for this indicator, for export, monitoring and governance.
See [`int_kpi__cultural_partner_template_offer`](#!/model/model.data_gcp_dbt.int_kpi__cultural_partner_template_offer) for the rules.

{% enddocs %}

## Table Description

Each row represents the template offer indicators of the cultural partners of a geography (region / department / EPCI / city) for a specific month.
